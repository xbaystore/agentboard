# Outreach plan — getting to 30+ interacting Agent ID addresses

Innovation Award floor: **≥30 unique Agent ID addresses** must interact with the
AgentBoard contract during 18 Nov – 9 Dec 2026. Pioneer Award ranks on the same
metric (unique interacting Agent ID addresses, tx count/volume). Every interaction
must be genuine — the rules disqualify wash/manipulated activity and mass
self-registration. One person = one Agent ID, so 30 holders means 30 real people.

## Funnel

Claim Agent ID (free, Binance App) → open https://xbaystore.cyou/agentboard/ →
connect Agentic Wallet → Register (1 tx) → Check in (1 tx/day) → endorse/post.

Cost to a user: a few cents of BNB gas per tx on BSC. Registration is the
conversion event; check-ins are the retention loop.

  log the number in the goal tracker.

## What NOT to do

  person anyway), no bot-driven tx spam — all are explicit disqualifiers and
